# DocSorter

Личный архив документов: фотографируешь бумагу телефоном — она сама попадает в
нужную категорию, получает название, дату, сумму, теги и связи с другими
документами. Дальше ищется словами: «счета от o2 за прошлый год».

Ставится на свой сервер, работает как приложение на телефоне (PWA), файлы лежат
зашифрованными.

## Из чего собрано

| Часть | Что | Почему так |
|---|---|---|
| Приложение | React + Vite, PWA | ставится на айфон через Safari, без Apple Developer |
| Сервер | Node 22 + Fastify | один процесс отдаёт и API, и фронтенд |
| База | PostgreSQL 16 + pgvector | полнотекстовый поиск на трёх языках в одной базе |
| Файлы | зашифрованные блобы на диске | ключа рядом с данными нет |
| Разбор | Claude Code CLI по OAuth-токену | подписка вместо оплаты API |
| Очередь | таблица в той же базе | Redis не нужен, память слабого сервера цела |

Elasticsearch не берём: JVM съест больше памяти, чем весь остальной стек, а
Postgres на архиве в десятки тысяч документов справляется без разговоров.

## Запуск

```bash
cd app
cp .env.example .env
```

Заполнить три строки в `.env`:

```bash
openssl rand -base64 32   # → POSTGRES_PASSWORD
openssl rand -hex 48      # → SESSION_SECRET
claude setup-token        # → CLAUDE_CODE_OAUTH_TOKEN
```

Поднять:

```bash
docker compose up -d --build
```

Создать себе вход (пустой ввод пароля сгенерирует случайный на 64 символа):

```bash
docker compose exec app node dist/scripts/create-user.js
```

Включить второй фактор:

```bash
docker compose exec app node dist/scripts/setup-totp.js
```

Открыть `http://localhost:8433`.

## На сервере, наружу

Указать домен в `.env` (`DOMAIN=docs.example.com`), направить на сервер A-запись
и поднять с профилем `public` — Caddy сам возьмёт сертификат:

```bash
docker compose --profile public up -d --build
```

Безопаснее не открывать порт в интернет вообще, а зайти в частную сеть
(Tailscale, WireGuard). Тогда профиль `public` не нужен: приложение слушает
`127.0.0.1:8433`, и достаточно проброса внутри своей сети. HTTPS для PWA всё
равно понадобится — Tailscale выдаёт сертификат командой `tailscale cert`.

Ограничить доступ по адресам можно прямо в `Caddyfile` — там заготовлен
закомментированный блок `@notmine`.

### Поставить на айфон

Открыть сайт в Safari → «Поделиться» → «На экран «Домой»». Дальше это обычная
иконка: своё окно, без адресной строки, вход помнится.

## Перенести старый архив

Скрипт работает по HTTP, поэтому запускается с ноутбука и годится и для
локального, и для удалённого сервера. Метаданные из `.md`-сайдкаров старого
DocSorter подхватываются как подсказки, полный разбор идёт следом в фоне.

```bash
node app/tools/import-vault.mjs \
  --url https://docs.example.com \
  --login daniil \
  --from ~/Documents/MyVault/Life/Dokumente
```

Флаги: `--no-analyze` — только залить файлы, не гонять модель; `--limit 20` —
попробовать на двадцати файлах; `--totp 123456` — если включён второй фактор.

Дубликаты определяются по SHA-256 содержимого, повторный запуск ничего не
испортит.

## Как устроена защита

Что сделано:

- пароль от 24 символов, проверяется argon2id (64 МБ памяти на попытку);
- **файлы зашифрованы AES-256-GCM**. Ключ шифрования (DEK) лежит на диске
  завёрнутым в ключ, выведенный из пароля через scrypt. Развёрнутый DEK живёт
  только в оперативной памяти процесса;
- перезапуск сервера запирает архив: пока не введёшь пароль, файлы не
  расшифровываются и фоновый разбор стоит на паузе;
- второй фактор TOTP;
- блокировка после 8 неудачных попыток на 15 минут, счётчик запросов на все
  маршруты;
- cookie сессии подписана, `httpOnly`, `secure`, `sameSite=lax`;
- регистрации нет вообще: пользователь заводится только из терминала сервера;
- журнал доступа в таблице `audit_log`;
- смена пароля не перешифровывает архив — меняется только обёртка вокруг DEK;
- service worker не кладёт `/api/` в кэш, документы в браузере не оседают.

Чего **нет**, и это важно понимать:

- **распознанный текст лежит в Postgres открытым**. Иначе полнотекстовый поиск
  невозможен: чтобы искать по словам, сервер обязан эти слова видеть. Зашифрованы
  сами сканы, метаданные и текст — нет;
- значит, кто получил диск сервера, прочитает текст документов. Лечится слоем
  ниже приложения: держи `data/` на LUKS-разделе или на `gocryptfs`-точке
  монтирования;
- сервер видит содержимое документов в момент разбора — иначе он не смог бы их
  разбирать. Полностью слепой сервер и автосортировка друг с другом несовместимы;
- модель видит содержимое документа: разбор идёт через Claude.

Забытый пароль = потерянный архив. Восстановления нет по устройству. Сохрани
пароль в менеджер паролей сразу.

## Настройки

Всё в `.env`, полный список с пояснениями — в `.env.example`.

| Ключ | Смысл |
|---|---|
| `AI_PROVIDER` | `cli` (подписка) · `api` (ключ Anthropic) · `off` (только офлайн-OCR) |
| `AI_MODEL` | `claude-haiku-4-5` — самая быстрая; `claude-sonnet-5` — точнее и дороже |
| `EMBEDDINGS_PROVIDER` | `none` — полнотекстовый поиск; `voyage` — плюс векторный |
| `WORKER_CONCURRENCY` | сколько документов разбирать разом; на 1 ГБ памяти оставь `1` |
| `REQUIRE_TOTP` | не пускать без второго фактора |
| `MAX_UPLOAD_MB` | предел на один файл |

### Про эмбеддинги

У Claude нет своего эндпойнта эмбеддингов, поэтому векторный поиск требует
отдельного поставщика и по умолчанию выключен. Без него поиск работает так:
модель превращает фразу в план (ключевые слова + фильтры по дате, отправителю,
категории), Postgres достаёт кандидатов полнотекстовым поиском на русском,
немецком и английском сразу, модель переранжирует найденное и отвечает словами.
На личном архиве это точнее наивного векторного поиска и не стоит ничего сверху.

Понадобится вектор — впиши `EMBEDDINGS_PROVIDER=voyage` и ключ, схема БД уже
содержит колонку `embedding vector(1024)`; ранее загруженные документы
переиндексируются кнопкой «Переразобрать».

## Обслуживание

```bash
docker compose logs -f app            # что происходит
docker compose exec db psql -U docsorter docsorter   # залезть в базу
```

Бэкап — две вещи, обе обязательны:

```bash
docker compose exec -T db pg_dump -U docsorter docsorter | gzip > dump.sql.gz
tar czf blobs.tar.gz app/data/blobs
```

Блобы без базы бесполезны (в базе `blob_key` и метаданные), база без блобов —
тоже. Пароль храни отдельно от обоих: без него `data/blobs` не расшифровать.

## Что внутри

```
app/
├── db/init.sql              схема: документы, сущности, связи, очередь, журнал
├── server/src/
│   ├── crypto/              вывод ключей, AES-256-GCM, состояние «архив открыт»
│   ├── storage/             блочное хранилище зашифрованных файлов
│   ├── ai/                  claude CLI и Anthropic API за одним интерфейсом
│   ├── pipeline/            разбор, OCR-резерв, сущности, связи, очередь
│   ├── auth/                вход, сессии, TOTP, журнал
│   ├── docs/                загрузка, список, карточка, правка, связи
│   ├── search/              полнотекстовый + векторный поиск, план и переранжирование
│   └── scripts/             создание пользователя, TOTP
├── web/src/                 PWA: поиск, загрузка, архив, карточка, настройки
├── tools/import-vault.mjs   перенос старого архива по HTTP
└── docker-compose.yml
```
